## Запуск

```bash
git clone https://github.com/BAITC-Hacks/hack-79a39f16-imokazakhstan.git
cd hack-79a39f16-imokazakhstan
cp .env.example .env   # впиши свои API-ключи
```

**Вариант 1 — через [uv](https://docs.astral.sh/uv/) (рекомендуется):**

```bash
uv run streamlit run app.py
```

**Вариант 2 — через pip:**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
streamlit run app.py
```

Приложение откроется на http://localhost:8501
