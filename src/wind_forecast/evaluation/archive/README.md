# Результаты удалённых экспериментов

Сохранена информация; экспериментальные веса, датасеты-кеши и запускатели удалены по просьбе пользователя. Исходный код доступен в git до cleanup: cc5581e. Ссылки на старые файлы в research-notes-before-cleanup.md — исторические, локальные артефакты по ним могут отсутствовать.

Проверены 19 конфигураций на 33 263 парах за февраль 2025 — январь 2026, выпуск ежедневно в 06:00 UTC+5, горизонт 48 часов с шагом час. Лучший одиночный прогноз мощности — CatBoost + история соседа: RMSE 0.335738, MAE 0.290722. Предыдущая модель: 0.340804/0.279409; улучшение RMSE сопровождается ухудшением MAE. Ансамбль: RMSE 0.335107, выигрыш слишком мал для усложнения.

GPU patch-transformer: RMSE 0.349689; Chronos Small LoRA: 0.367962; Base LoRA: 0.378582. Они не оставлены в production-наборе. ARIMA/GRU/LSTM/Graph-GRU и остальные варианты — в models-comparison.csv. Подробные настройки, месячные fits и метрики — experiment-reports.json.

Ветер: ExtraTrees RMSE 3.477819 м/с, MAE 2.882098 м/с; среднее 3.641736, persistence 4.670762. Модель ветра сохранена. Мощность прогнозируется отдельно напрямую. Ошибки остаются заметными, будущая погода пока не используется. Номинальная мощность неизвестна, прогноз 0–1 нельзя автоматически переводить в МВт. Факта февраля 2026 нет.

Brev оставлен работающим по последней просьбе пользователя; эта очистка локальная. Тариф инстанса $4.224/час, это не счёт. Приблизительная стоимость 355 секунд GPU-suite $0.417, без подготовки и простоя. Локальная мощность: около 0.015 секунды на две турбины.
